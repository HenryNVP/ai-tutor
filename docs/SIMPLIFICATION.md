# Simplification Guide

## Demo Mode

When `demo_mode: true`:
- ❌ Personalization disabled
- ❌ Adaptive difficulty disabled
- ❌ Progress tracking disabled
- ✅ Static "stepwise" style
- ✅ Documents cached (no chunking/embedding)
- ✅ Keyword-based routing only

## Completed Simplifications

- ✅ CLI removed
- ✅ Session management simplified (one session per learner)
- ✅ Routing simplified (keyword-based only)
- ✅ Demo mode flag added
